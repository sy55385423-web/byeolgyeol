# 리포트 검증 스크립트

규칙 DB(`lib/knowledge/`)를 손대면 이 넷을 돌린다. LLM 없이 돌아가는 엔진이라
잘못된 문장이 그대로 사용자에게 나간다. 눈으로는 못 잡는 것들을 여기서 잡는다.

| 스크립트 | 무엇을 보는가 |
|---|---|
| `check-reports.mjs` | 1,050건 생성 — 문장 반복·조사·마침표·빈 문단·금지 표현·예외·분량·문단 수 |
| `check-josa.mjs` | 명식 낱말(오행·천간·지지·십신·격) 뒤 조사가 받침과 맞는지 전수 대조 |
| `check-repeats.mjs` | 한 섹션 안에서 같은 어구가 두 번 나오는 자리를 빈도순으로 |
| `check-ontopic.mjs` | 문항에 들어간 규칙이 **같은 계열**인지 (연애 질문에 건강·점성이 섞이면 실패) |
| `check-monthyear.mjs` | "N월"이라고만 하고 연도를 안 대는 문장이 남았는지 (용신 달은 매년 돌아온다) |
| `check-truesolar.mjs` | 진태양시 보정이 실제로 시주를 바꾸는지 · 출생지·과거 표준시 반영 확인 |
| `check-crossrepeat.mjs` | **리포트 전체**에서 같은 문장이 여러 섹션에 반복되는지 (0이어야 한다) |
| `check-coverage.mjs` | 200명 × 17주제 — 주제별로 걸리는 규칙이 몇 개인지 (최소 3 미만이면 구멍) |
| `check-consistency.mjs` | 한 리포트가 "필요한 기운"을 용신 하나로만 말하는지 (lacking과 섞이면 모순) |
| `check-radar.mjs` | 레이더 5축이 명식에서 갈리는지 (seed 해시였다) |
| `check-values-audit.mjs` | **전수 감사** — 71문항의 답이 모두 명식에서 갈리는지. "한 값 고정"이 0이어야 한다 |
| `check-values.mjs` | 제목에 쓰는 답이 명식에서 갈리는지 · 한 값으로 쏠리지 않는지 |
| `check-preview.mjs` | 결제 전 미리보기 카드 한 줄이 어떤 값과 붙어도 말이 되는지 |
| `check-personal.mjs` | **고정문장**(90% 이상에게 같은 문장) 비율과 **변별력**(두 사람 리포트 차이). 목표 20% 이하 / 70% 이상 |
| `check-gender.mjs` | 성별만 바꿨을 때 리포트가 실제로 달라지는지 · 대운 순역이 양남음녀 원칙과 맞는지 |
| `check-grounding.mjs` | **근거 밀도** — 섹션마다 간지·십신·오행·12운성·신살·수치가 몇 번 인용됐는지. 근거 0개 섹션이 있으면 실패 |

```
npx tsx scripts/check-reports.mjs
```

`check-josa.mjs`의 "사이/사이라"는 오탐이다. 12운성의 '사(死)'가 낱말 '사이'에 걸린다.
